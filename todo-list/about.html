ჩემ შესახებ

ინფორმაცია ჩემი განათლების, ინტერესებისა და პროფესიული მისწრაფებების შესახებ

ვინ ვარ მე?

მოგესალმებით! მე ვარ საბა, ტექნოლოგიებითა და ვებ-დეველოპმენტით გატაცებული დეველოპერი. ჩემი მიზანია შევქმნა ციფრული პროდუქტები, რომლებიც ადამიანებს ყოველდღიურ ცხოვრებასა და საქმიანობას უმარტივებს.

ვებ-დეველოპმენტის შესწავლა დავიწყე საფუძვლიანად — სემანტიკური HTML5-ის პრინციპებით, რადგან მიმაჩნია, რომ ძლიერი და ხარისხიანი ვებ-გვერდის საფუძველი სწორედ სტრუქტურულად გამართული მარკირებაა.

ყოველდღიურად ვმუშაობ ახალ პრაქტიკულ ამოცანებზე, ვქმნი მრავალფეროვან კომპონენტებს და ვსწავლობ მსოფლიო დონის საუკეთესო პრაქტიკებს: Clean Code, Responsive Design, Tailwind CSS და Web Accessibility (A11y).

„კარგი კოდი არის ისეთი კოდი, რომელსაც არა მხოლოდ კომპიუტერი კითხულობს, არამედ მარტივად ესმის ადამიანსაც.“ — დეველოპერის პრინციპი
